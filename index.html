A style guide that directly follows Ant Design's real design tokens — color system, spacing, radius, shadow, and type scale — with Shield Legal's own blue as the one customization.
See the dashboard example →

Overview

Every foundation on this page is Ant Design v5's actual default value, sourced and verified — not an approximation of Ant Design's look. The single deliberate customization is color: Shield Legal's brand blue (#18ABED) replaces Ant Design's own default blue as the seed for the primary ramp, generated with Ant Design's own palette algorithm. Everything else — the neutral grays, the functional colors' structure, the spacing and radius scales, the shadow formulas, the type scale, and each component's proportions — is Ant Design's, unchanged.

Every component below is live — click the buttons, open the select, toggle the switch, dismiss the tag and alert, page through the pagination. This is a plain, self-contained site: three files (this page, a stylesheet, a small script), no build step, no external fonts, no framework. Open dashboard.html to see the same components assembled into a real screen.

Color

Shield Legal's blue, expanded into a 10-step ramp with Ant Design's own palette generator. Step 6 is the seed (#18ABED); every other step is derived from it.

brand-blue (step 6) is the logo and large-graphic color — 2.6:1, not text-safe. brand-blue-dark (step 8) carries every button, link, and selected state. Ant Design's own convention would use the base color directly, or step 7 for an active state; both fall under a 4.5:1 text floor, so this system's action color sits one step further down the ramp than Ant Design's own default pattern.

None of the three text colors above are Ant Design's own literal functional colors. Ant Design's actual defaults — #52C41A, #FAAD14, #FF4D4F — measure 2.3:1, 1.9:1, and 3.3:1 against white, all well under a 4.5:1 text floor. (Amber/gold warning colors are a known, common accessibility weak point across design systems generally — Ant Design's is no exception.) Each token above is that same color's own Ant Design ramp, pushed to the first step that actually clears 4.5:1.

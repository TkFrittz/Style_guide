Shield Engineering

A hand-rolled component library — plain CSS, no framework — in Shield Engineering's own visual language.

Overview

This system started as Ant Design v5's tokens recolored with Shield Engineering blue. Ant Design has since been removed from the app entirely — every component is now a small, self-contained React component styled with plain CSS classes (shield-*), documented here class for class from src/styles/tokens.css and src/styles/ui.css.

What survived the rebuild: the color ramp and its contrast math, the 8-step spacing scale, the radius steps, and the three-layer shadow formulas — all originally derived from Ant's methodology, none of it Ant's code anymore. What's new: two brand webfonts (Fraunces for headings, Satoshi for body) in place of the system-font stack, a full set of Font Awesome (Classic, Solid) icons replacing @ant-design/icons, and real light/dark theming via a data-theme attribute — try the toggle in the sidebar (the sidebar's own background, the sider-bg token, themes with it too).

Everything below is a working component, not a screenshot — open the select, flip the switch, dismiss a tag, push a toast.

Each mood is a text color on a saturated mid-tone background (not a pale tint). In light mode, text on its own background measures 5.9:1 for success, 7.8:1 for warning, 5.3:1 for error and 4.9:1 for info — all above the 4.5:1 target. Dark mode uses its own values (see tokens.css): success measures 4.8:1 there (above the target), while warning (3.4:1), error (2.7:1) and info (3.2:1) fall below 4.5:1. Info has separate light and dark values — light uses blue-9 for its text, dark uses blue-8. For comparison, Ant's raw defaults — #52C41A, #FAAD14, #FF4D4F — measure 2.3:1, 1.9:1 and 3.3:1 on white; the text colors above are the same ramps pushed to a much darker step.

Typography

Fraunces carries headings and the brand mark; Satoshi carries body copy and every control. Both are variable fonts (every weight from light to black is available) downloaded into this project's fonts/ folder — Fraunces from Google Fonts, Satoshi from Fontshare — no system-font fallback in normal use, just a system sans-serif fallback stack if the font files fail to load.

Small text — --weight-small

Satoshi looks light at small sizes, so small text and control labels (buttons, tabs, menu items, tags, table cells, captions, alerts, toasts, step titles, stat labels) use --weight-small (500) instead of the normal 400. Everything else (paragraphs, typed input text) stays at 400. Change that one token in tokens.css to adjust all of it at once.

Button Live

Seven looks: Primary, Default, Dashed, Text, Link, Danger and Danger (default), plus a Disabled state. Primary fills with blue-7 (#0A85C7, one step lighter than brand-blue-dark) and darkens to blue-8 on hover, not the base brand color — see Color, above. White text on blue-7 measures 4.0:1, a little under the 4.5:1 target. Button colors in components.css read from the color tokens in tokens.css (brand-blue-dark, error, border and so on), so changing a token also changes the buttons. Buttons are pill-shaped (42px radius), use the small-text weight, and only the two main-action buttons (Primary and solid Danger) carry a faint, soft shadow, with its own hover values.

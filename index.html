Shield Legal

A hand-rolled component library — plain CSS, no framework — in Shield Legal's own visual language.

Overview

This system started as Ant Design v5's tokens recolored with Shield Legal blue. Ant Design has since been removed from the app entirely — every component is now a small, self-contained React component styled with plain CSS classes (sl-*), documented here class for class from src/styles/tokens.css and src/styles/ui.css.

What survived the rebuild: the color ramp and its contrast math, the 8-step spacing scale, the radius steps, and the three-layer shadow formulas — all originally derived from Ant's methodology, none of it Ant's code anymore. What's new: two brand webfonts (Catamaran for headings, Lexend for body) in place of the system-font stack, a full set of LLM-generated stroke icons (Feather/Lucide-style, see Icons) replacing @ant-design/icons, a permanently-dark navy sidebar, and real light/dark theming via a data-theme attribute — try the toggle in the sidebar.

Everything below is a working component, not a screenshot — open the select, flip the switch, dismiss a tag, push a toast.

Icons

Not hand-drawn, and not from a licensed icon package either — these are LLM-generated inline SVGs, written to match the visual convention of open-source stroke-icon sets like Feather Icons and its maintained fork Lucide (both MIT-licensed): 24×24 viewbox, 2px stroke, round caps and joins, currentColor, no fill. Avatar & Badge

Avatar — sizes JT JT JT

24 dense rows & table cells   32 default — headers, menus, most lists   40 profile headers & detail panels   icon fallback no name/initials yet, e.g. an unassigned contact

Badge — dot JT

A corner-overlaid marker with no number — means "something here needs attention," not "how many." Always paired with an avatar or icon, never used on its own.

Badge — count Notifications3

Unlike the dot, count doesn't corner-overlay anything — it renders as a plain inline chip meant to sit right after a label. This is the exact markup behind the "Offers" count in the Menu section below.

Badge — count, on-dark Offers12

The same count chip, recolored for the permanently-dark sidebar — use on-dark only against sider-bg, never on a light surface.
